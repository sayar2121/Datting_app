# HeartSync

HeartSync is a premium dating and experiences platform built with React, TypeScript, and Vite. It offers a seamless, highly responsive, and aesthetically pleasing user interface for users looking to find meaningful connections and plan perfect dates.

## Features

- **Premium UI/UX:** A beautifully designed interface with modern aesthetics, utilizing smooth animations and an engaging layout.
- **Responsive Design:** Fully optimized for seamless use across desktop, tablet, and mobile devices.
- **Special Offers & Experiences:** Integrated marketing pages for special deals, room decor, events, and other romantic experiences.
- **Dynamic Routing:** Built with React Router for efficient and fluid navigation.
- **Micro-animations:** Incorporating `framer-motion` for subtle, engaging interactive states.

## Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite
- **Language:** TypeScript
- **Routing:** React Router v6
- **Styling:** Custom CSS with a focus on modern design principles
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository and navigate to the project directory:
   ```bash
   cd Datting_app
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

To start the development server, run:
```bash
npm run dev
```

Open your browser and visit `http://localhost:5173` (or the port specified by Vite) to view the application.

### Building for Production

To create a production build, run:
```bash
npm run build
```
This will compile the TypeScript code and bundle the application into the `dist` directory. You can preview the production build locally by running:
```bash
npm run preview
```
